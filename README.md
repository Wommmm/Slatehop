# SlateHop

SlateHop 是基于 RustDesk 二次开发的 macOS 远程桌面工具。在一台 Mac 上输入另一台 Mac 的连接地址和远控密码，就能看到它的桌面、操作键鼠、复制文字或传文件。常用设备可以起名保存在首页，下次直接点选。[RustDesk 上游源码](https://github.com/rustdesk/rustdesk)

## 第一次连接自己的两台 Mac

假设你要在 MacBook 上操作一台 Mac mini。先在 **Mac mini** 上准备连接信息，再到 **MacBook** 上发起连接。

1. 在 Mac mini 上打开 SlateHop，确认服务已启动。在「设置 → 安全」开启「允许 IP 直接访问」。如果要用密码连接，请启用固定密码，并允许通过密码接受连接。
2. 打开「设置 → 设备管理」，在「这台 Mac」下点「复制地址」。复制的内容包含 IP 和端口。如果没有显示地址，请先检查直连开关、服务状态和这台 Mac 的网络连接。
3. 想自己管理远控密码时，在同一页设置并保存一个**管理密码**。再点「设置或重置远控密码」，输入管理密码和你选的新远控密码。第一次保存管理密码会保留原有远控密码。以前在其他入口设过的密码可能无法回显，可以在这里重新设置一个。
4. 在 MacBook 的 SlateHop 首页粘贴地址，输入**远控密码**，点「连接」。以后要找回这个远控密码，在 Mac mini 的「设备管理」输入管理密码，点「验证后查看远控密码」，再点「显示密码」或「复制密码」。

管理密码自己保管。别人连接时，只需要你给的地址和远控密码。两台 Mac 可以互换角色，每台分别管理自己的密码。

## 自己用，还是交给别人用

| 使用场景 | 密码和租期怎么管 |
| --- | --- |
| 自己的 Mac | 本机密码管理是可选功能。可以直接在「这台 Mac」设置管理密码和远控密码，无需先登记设备或配置 SSH。 |
| 机主托管的 Mac | 本机自用入口会锁定。机主通过管理通道续期或重置远控密码。续期保留原密码，重置后，新连接使用新密码。租客用拿到的地址和远控密码连接。 |

托管设备在新连接时校验密码和租期。首页设备记录里的截止时间，来自这台设备上一次成功认证的回复。续期后，重新连接就能刷新记录。[托管说明](docs/host-access.md)

## 连接后可以做什么

- **操作桌面**。使用本机的鼠标和键盘操作远端 Mac，复制、粘贴文字，或把远端截图保存到本机。
- **调整画面**。会话的图像质量可以选「平衡」或「速度最优化」。平衡适合阅读和日常操作。网络吃紧、拖动窗口感觉迟钝时，可以试试速度最优化，它会优先响应，细节可能变少。实际延迟也取决于两端之间的网络。
- **传文件**。查看每个文件的进度，按需取消单项传输。遇到同名文件可以选择覆盖或跳过。
- **再次连接**。在首页保存设备名称、地址，并选择是否记住远控密码。断开后可以从同一条记录重连。

## 连接时遇到问题

| 看到的现象 | 先检查哪里 |
| --- | --- |
| 连不上对方的地址 | 确认被控 Mac 的直连服务正在监听，双方之间有可达路由。跨网络时，可以先接入双方都能互访的 VPN，再使用对方可达的地址和端口。 |
| 显示「等待画面传输」 | 在**被控 Mac** 打开「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」（部分系统叫「屏幕录制」），允许当前使用的 App。按系统提示退出并重新打开 App，再从控制端点「重连」。自行构建的 App 在权限列表里可能显示为 RustDesk。 |
| 能看到画面，无法点击或打字 | 在**被控 Mac** 的「系统设置 → 隐私与安全性 → 辅助功能」允许当前使用的 App。 |
| 提示密码错误或已过期 | 自用设备回到「这台 Mac」查看或重设远控密码。托管设备请联系机主核对密码和租期。 |
