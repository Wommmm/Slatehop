# SlateHop

SlateHop 是基于 RustDesk 二次开发的 macOS 远程桌面工具。它把**设备地址、远控密码和常用设备列表**放在连接首页，让你从一台 Mac 连接另一台 Mac，直接操作远端桌面。[RustDesk 上游源码](https://github.com/rustdesk/rustdesk)

## SlateHop 做了哪些改动

- **按地址直连**。输入目标 Mac 的地址和远控密码即可发起连接。连接中断后，网络恢复时可从原来的设备记录重新连接。
- **管理常用设备**。给设备起名，在本机保存、编辑或删除连接记录。可以按设备选择是否记住密码。
- **支持有时限的远程访问**。被控 Mac 在每次建立新连接时校验凭证是否有效。连接建立失败时，客户端区分网络不可达、密码错误和凭证过期。
- **调整文件和截图操作**。传输时可查看各文件的进度并取消单项任务。遇到同名文件可以选择覆盖或跳过。远程截图保存到发起连接的 Mac，可自行选择位置和文件名。
- **重做 macOS 首页和设置**。连接首页改为设备列表与连接表单并排，首页和设置使用一致的磨砂视觉。应用菜单和 Dock 图标也换成了 SlateHop 的独立设计。

桌面画面、键鼠控制、双向文件传输和文字剪贴板等基础能力来自 RustDesk。SlateHop 在这些能力上调整了 Mac 用户日常的连接和操作流程。

## 开始连接

1. 在 Apple silicon Mac 上打开 `SlateHop.app`。如果拿到的是 ZIP，先解压，再把 App 放到「应用程序」。
2. 确认目标 Mac 正在运行兼容的主机服务，并且本机网络可以访问目标地址。
3. 填写设备地址和远控密码。经常连接的机器可以起个便于识别的名字，例如「工作室 Mac mini」。
4. 下次从设备列表选择对应记录即可。共用电脑上建议每次手动输入密码。

## 查看租期与管理密码

在 Mac 的「设置 → 租期」里可以查看当前账户的到期时间。要查另一台 Mac，请看设备列表里对应的连接记录。记录显示那台设备上次认证时返回的时间。续期后，重新连接即可更新记录。

机主可通过独立的管理通道给受管 Mac 延长租期或重置远控密码。续期保留现有密码。重置后，新连接需要使用新密码。租客的设置页只显示日期，机主可以在自己的管理终端将新密码交给租客。[机主管理说明](docs/host-access.md)

## 使用提示

连接成功但看不到桌面时，可以检查**被控 Mac** 的屏幕录制权限。能看到画面却无法点击或输入时，检查被控 Mac 的辅助功能权限。远控密码用于建立连接。进入远端 macOS 的登录界面时，使用那台机器自己的系统账号密码。

如果需要反馈问题，请在 Issues 里提供 macOS 版本、SlateHop 版本、复现步骤和实际现象。提交截图或日志前，请遮盖设备地址、账号和密码。
